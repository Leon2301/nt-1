\Large Exercise 1 
Spare change

Imagine a world in which we have exactly two types of coin: 
one worth $P$ cents, 
one worth $Q$ cents, 
such that $\gcd{P,Q}$. The goal of this
problem is to bound how many values we cannot form using these coins. 


(i) (15pts)
Let us first consider $P = 5, Q = 13$. Determine in how many
ways we can form 48 cents using these two coins.

Hint: Consider the Diphantine equation $5u+13v=48$.
What is the general form of the solution? We can't have a negative number of coins!

solution: 

we must find awnsers for the following equasion.

    u \leq 9 <\frac{48}{5}, v \leq 3 < \frac{48}{13}
\end{align*}

(ii)  (20pts)
Show that we can form 49, 50, 51, 52 cents using coins worth
$P=5$ and $Q=13$. Here conclude that we can form any value 
$N \geq 48$.

solution: 
\begin{align*}
    49 = 2(5) + 3(13) \\
    50 = 10(5) + 0(13) \\
    51 = 5(5) + 2(13) \\
    52 = 0(5) + 4(13) 
\end{align*}


So at first we see that every number with it's last digit be
$0$ or $5$ we can easily express through coins of $P = 5$
Therefor any number
\begin{align*}
S = \{ n \in \bN_{0} : n \%10 = 0 \lor 5 \} \\
5|s , \forall s \in S
\end{align*}
So we just need to show that $(k13)\%5, k \in \bN_{0}$ gives us the last digits ${1,2,3,4}$
while $k13 \leq 52$

it does!
\begin{align*}
    k = 1 : 13\%5 = 3 \\
    k = 2 : 26\%5 = 1 \\
    k = 3 : 39\%5 = 4 \\
    k = 4 : 52\%5 = 2 \\
\end{align*}

(iii) (15pts)
Can we form 47 with coins worth $P=5$ and $Q=13$?

solution: 
no. 

$47\%5 = 2$ and we saw in (ii) that we need at least $4(13)=52$
four coins to form such a number. But 52 already overshouts 47 
and negative coins are not allowed.

(iv) (20pts) 
Define $g(P,Q) = PQ - P -Q$.
Show that $g(P,Q)$ cannot be formed using coins worth $P$ and $Q$

(v) (20pts)
Suppose that $P<Q$. Show that, for $N = 1, 2, ... , P$, we can write
\[
N = aP + bQ
\]
with 
\[
0 < a < Q, b+P > 0.
\]
Hint: Start by showing we can find a solution with such an $a$
and show that corresponding $b$ satisfies the given inequality. 
Recall that $N-bQ > -bQ$


(vi) (10pts)
Hence conclude that $g(P,Q)$ is the largest value that cannot be 
formed using coins with $P$ and $Q$.
